# Security Policy

## Supported Versions

Security fixes are considered for the latest version of High Performance Tool. Older releases may not receive security updates.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please report it privately to the project maintainer rather than opening a public issue.

You can use GitHub's **Report a vulnerability** feature on the repository's Security tab, if it is enabled. If that option is unavailable, contact the maintainer through the contact information listed on the GitHub profile.

When reporting a vulnerability, include:

- A clear description of the issue.
- Steps to reproduce it, if known.
- The potential impact.
- Any relevant screenshots, logs, or proof of concept that do not expose personal or sensitive information.

Please avoid publicly disclosing the issue until the maintainer has had a reasonable opportunity to review it.

## Scope

High Performance Tool is a Windows utility that interacts with Windows power plans through `powercfg`. Reports involving the application, its code, or its distribution are in scope.

This project cannot address vulnerabilities in Windows itself or unrelated third-party software. Such issues should be reported to the relevant vendor.

## Response

The maintainer will review reports as time permits and may ask for additional information. There is no guaranteed response or remediation timeline for this project.

Thank you for helping keep High Performance Tool and its users safe.
